# TY Gateway ARM64 设备软件包

更新：2026-10-01。本包是在已正常启动联网的 Armbian 上的软件 overlay，不是整盘镜像，不改内核、Loader、DTB、分区或设备 MAC。

新设备请使用同版本 GitHub Release 的 bootstrap-oec.sh。它自动准备运行依赖和固定官方 DAE，再安装签名软件包。直接运行 overlay 安装器只适用于依赖已经准备好的维护环境；SHA256SUMS 不能代替发布签名。

## 首次联网

管理员先预登记真实有线 MAC，主路由 DHCP 保持开启。设备自动认领并保存独立身份，获取规则、订阅及设备级 FRP，无需激活文件或共享密码。FRP 使用原生 OIDC 加设备端口授权，控制端口 7001，SSH 映射池 22000–22999，由 Agent 管理 FRPC 子进程。

核心管理服务开机启动，代理、DHCP 和局域网 DNS 新装默认关闭。转发预检与 NetworkManager 接口重连处理随包安装，代理开关状态持久保存；真实流量与重启行为仍需实机验收。

## 管理与恢复

本地入口 http://<设备局域网IP>:8088，四菜单：设备与局域网、代理与规则、更新与备份、密码管理。首次设置密码，设备码不是密码。设备发现来自本机邻居/租约，不能保证显示所有休眠客户端；加入绑定后仍需保存应用。

节点使用 DAE 验证清单，排除名称含 IPV6 的节点，失败保留上一有效版本。域名/IP规则、地区/手动/自动/显式故障转移及最多6小时的可取消临时模式已包含；候选节点展示不等于测速或实时出口。

签名在线/离线升级保留身份和用户配置。用户只能升级，管理员可受控回退。导出/导入/重置用户设置不覆盖注册与 FRP，也不是整机擦盘；重置保留网络入口、本地密码、管理员基础方案。彻底重刷删除身份后需管理员重置认领；不要重复清理已经重新登记并安装的测试设备。

v0.8.8 的设备内部 HTTPS 通道为 8443，管理员网页仍不带端口。旧 stock 地址与凭据地址只作受控单向迁移，不换设备身份。分类节点选择由本机 DAE 验证并保存，常规云端同步保留本地选择；自定义规则、导入和重置目前仍需云端。DAE 只接管 LAN，设备管理 DNS 不依赖本机代理；详见仓库的 `docs/LOCAL-PREFERENCES.md`。

## 构建和边界

v0.8.9 纳入 LAN DNS 动态交接及旧内核透明入口兼容：代理/DNS可用时转交 DAE，关闭或不可用时恢复直连；Linux 6.6 之前在 DAE 启动和重载后自动校正入口，新内核跳过，不替换内核或 DAE。6.1.157 测试机 Windows YouTube 在 DAE 重启后已确认可用；全新首装及整机重启仍待新轮验收。详见仓库 `docs/LAN-DNS-HANDOFF.md` 与 `docs/DAE-KERNEL-COMPATIBILITY.md`。

从同一干净提交构建四个 ARM64 Go 程序，组包时传入明确路径及固定官方 FRPC。签名包、独立验签器与 bootstrap 必须一致。公开包不含设备身份、订阅/节点秘密、FRP 密码、发布私钥或生产数据库。

Pilot 仅分发至 GitHub，不触及 R2/Guide。完全离线首装仍受 apt 系统依赖限制，已安装设备的签名离线升级不依赖 GitHub。完整功能及未完成项见仓库 docs/FEATURES.md，当前安装入口和实机流程见 README.md 与 docs/OEC-PILOT-ACCEPTANCE.md。
