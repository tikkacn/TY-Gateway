# 功能实现与验收边界

更新：2026-10-01；v0.8.5 Pilot。实现表示源码和软件包包含，不表示每项都通过新一轮实机验收。

| 功能 | 当前实现 | 本轮实机重点 |
| --- | --- | --- |
| MAC准入/自动注册 | 一份通用安装器，预登记真实MAC后认领；设备独立身份落盘，无逐台激活文件 | 两台不串身份；重新从1/2编号 |
| 自动FRP | 设备级OIDC、7001控制端口、22000–22999专属端口 | 公网SSH握手、重启恢复 |
| 一键首装/中断重跑 | 安装运行依赖、官方DAE和程序；保留已有配置；核心服务开机启动 | 新刷Armbian无需手工补服务 |
| DAE开关/转发保护 | 默认关、用户状态持久；IPv4/IPv6预检及NetworkManager重连处理 | 真实路径及重启后状态 |
| 规则方案/节点 | 本地缓存、失败保留上一版；DAE解析清单；按IPV6名称过滤 | 节点显示与DAE清单一致 |
| 分流选择 | 紧凑按钮；直连、自动、地区/手动、显式故障转移；验证节点候选 | 指定规则实际出口、备用策略 |
| 自定义规则 | 域名及IP/CIDR；节点使用原始显示名称；用户规则优先 | 域名/IP命中及优先级 |
| 临时模式 | 取消按钮；5/10/30分钟、1/3/6小时，到期恢复 | 取消及到期真正恢复 |
| 保护和设备绕过 | 内网/救援强制保护；指定设备直连；维护信息不受客户重置影响 | 不因分流错误失联 |
| 本地管理 | 四菜单：设备与局域网、代理与规则、更新与备份、密码；发现设备及手工绑定 | 控件尺寸、点击/会话正常 |
| 更新/配置 | 签名在线和离线升级；用户不降级、管理员受控回退；导出/导入/重置用户配置 | 保留身份，实际应用及恢复 |
| 密码救援 | 设备绑定、签名挑战、10分钟一次性授权 | 离线密码恢复而非通用MAC密码 |
| 管理订阅统计 | 按订阅源展示，不把多个设备相同节点数累加；失败保留标注 | 多设备订阅数量不误导 |

## 已提出但仍未完成/不作保证

- 每节点测速结果绿黄红显示，以及用户自定义测速URL：尚未实现。
- 显示每个策略当前正在使用的实际出口：目前显示经DAE验证的候选节点，不是实时连接观察。
- 固定指定节点自动故障转移：固定选择不会自动切换；需使用显式故障转移模式设置备用。
- 完全离线的全新Armbian首装：系统依赖仍需apt；已安装设备的签名离线升级已提供。
- R2主备正式分发：按用户决定暂缓；本轮GitHub-only，另一项目分发不变。
- 所有ARM硬件兼容、Linux/内核在线升级和完整系统恢复出厂：不在当前软件包保证范围。

用户设置正常时按用户设置运行；管理员可在求助时明确重置，不在日常同步主动干预。用户配置备份不包含身份/FRP/订阅秘密；重置用户配置保留网络入口、本地密码、设备注册和管理员基础策略，不是擦除整机。
