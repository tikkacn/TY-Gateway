# 设备通道与分类节点本地保存（v0.8.8 Pilot）

## 用户与管理员的边界

分类节点选择保存到设备单一原子快照；页面不再先写云端。读取本机已验证规则与 DAE 节点清单，校验分类、节点和本地修订号，DAE 确认应用后才提交。失败保留上一版；写入失败则请求配置回退，回退未确认会明确提示。

常规拉取规则、节点和订阅会重新叠加本地选择，不主动覆盖客户偏好。只有管理员明确重置命令或用户导入/重置设置才清除旧本地覆盖。管理员重复收到同一重置命令不会再次清除后来保存的选择。临时全局模式仍覆盖普通分类；个人规则、管理员例外和内网/救援保护不参与分类改写。

固定节点暂时不可用时保留原选择意图，实际规则降为自动选择；节点恢复后的成功同步可重新应用。跟随方案默认保存为空覆盖，恢复方案原动作，而不是沿用旧云端偏好。备份导出读取本机有效偏好；整份设置导入/重置以及其他自定义规则操作目前仍需云端可用，不等于全部设置完全离线。

## HTTPS、DNS 与远程维护

管理员网页为 `https://oec.188811.xyz/admin`，设备内部注册、同步、FRP roster 和 OIDC 通道为 `https://oec.188811.xyz:8443`。同一 hostname 的旧 stock 443 凭据只允许单向迁移到 8443；自定义地址、不同 hostname、不同协议/路径或反向迁移仍被拒绝。身份和密钥不重新生成，原凭据受安装事务保护。

DAE 使用 LAN-only 接管和独立直连管理 DNS，避免设备自己的 DNS 依赖代理；配置重载不等待外网测速成功。客户主路由关闭 IPv6 的建议不变；服务器 8443 的 IPv6 监听不意味着客户 LAN 开启 IPv6。FRP 控制端口仍为 7001，设备 SSH 池仍为 22000–22999。服务器也须同步配置 roster/OIDC 的 8443；只升级设备不能修复服务器侧错误端口。

离线保存、冲突拒绝、失败不提交、普通同步保留和重复管理员重置由针对性测试验证。未做真实断网、重启和客户端指定出口流量测试；DAE active 或配置应用成功不等于证明手机/电脑真实走指定节点。旧阶段包按用户要求保留，R2 暂不使用。
